# Grade 11 — Information Technology: Term 3

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Networks and data processing
- **Key concepts:** network topologies, protocols, communication media, data validation, processing workflows, problem solving with arrays and files
- **Skills / outcomes:** explain network concepts and build programs that process larger volumes of data accurately
- **Assessment angles:** network diagrams, protocol questions, data-validation/debugging scenarios

### Social implications and integrated development
- **Key concepts:** privacy, security, computer crime, digital communication, PAT-style integration, system testing
- **Skills / outcomes:** evaluate the social impact of technology and complete more integrated development tasks
- **Assessment angles:** cybercrime scenarios, design-justification questions, integrated practical tasks

## Assessment
- **Formal tasks this term:** Alternative/integrated task, practical test and PAT-style solution development.
- **SBA weighting:** For Grades 10–11, 2023 ATP mediation indicates SBA converts to 40% and examinations to 60%; PAT work is built into the year programme.

## Notes
Term 3 usually blends theory and practical strands more tightly. Networks, social implications and coding should be studied as connected parts of real systems.
