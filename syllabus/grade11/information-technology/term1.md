# Grade 11 — Information Technology: Term 1

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Object-oriented programming foundations
- **Key concepts:** classes, objects, attributes, methods, constructors, GUI foundations, arrays and records or structures
- **Skills / outcomes:** design simple classes, instantiate objects and read or write basic object-oriented code
- **Assessment angles:** class design questions, code tracing, spotting misuse of object properties and methods

### Algorithms and file handling
- **Key concepts:** advanced algorithms, text and binary files, validation, procedural decomposition, problem solving
- **Skills / outcomes:** process files, structure larger programs and trace more complex logic than in Grade 10
- **Assessment angles:** file-processing snippets, algorithm dry runs, debugging and logic-correction items

## Assessment
- **Formal tasks this term:** Theory test and practical/programming test.
- **SBA weighting:** For Grades 10–11, 2023 ATP mediation indicates SBA converts to 40% and examinations to 60%; PAT work is built into the year programme.

## Notes
Schools may still teach the practical language in Delphi or Python. Grade 11 expects a visible shift from simple programming to class-based thinking and larger problems.
