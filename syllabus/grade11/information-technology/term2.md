# Grade 11 — Information Technology: Term 2

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Computer architecture and software engineering
- **Key concepts:** computer architecture, system components, software design process, testing, maintenance, modular planning
- **Skills / outcomes:** explain how hardware and software fit together and apply simple software-engineering steps to coding tasks
- **Assessment angles:** architecture short questions, software-lifecycle prompts, structured design answers

### Databases and SQL integration
- **Key concepts:** tables, forms, queries, SQL basics, linking code to databases, validation, data processing
- **Skills / outcomes:** write basic SQL, connect programs to database structures and manipulate data through forms and queries
- **Assessment angles:** SQL syntax, query outputs, normal data-validation and program-database integration questions

## Assessment
- **Formal tasks this term:** Mid-year practical examination and mid-year theory examination.
- **SBA weighting:** For Grades 10–11, 2023 ATP mediation indicates SBA converts to 40% and examinations to 60%; PAT work is built into the year programme.

## Notes
This term is a bridge into Grade 12 database and systems work. Learners should become comfortable switching between coding and structured data tasks.
