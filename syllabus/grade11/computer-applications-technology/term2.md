# Grade 11 — Computer Applications Technology: Term 2

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Networks, internet and social implications
- **Key concepts:** LAN and WLAN, wired and wireless connections, internet and WWW, websites, IoT, BYOD, privacy, security, cryptocurrency, big data
- **Skills / outcomes:** describe network setups, evaluate internet content and discuss current digital-social issues
- **Assessment angles:** network terminology, website-evaluation items, ethics and security case studies

### Integrated solution development
- **Key concepts:** spreadsheets, databases, information management, word processing styles, HTML and web design
- **Skills / outcomes:** use multiple applications together, manage information quality and build basic web pages and database solutions
- **Assessment angles:** control-test style integrated tasks, spreadsheet IF logic, query design and HTML syntax fixes

## Assessment
- **Formal tasks this term:** Control test and June examination.
- **SBA weighting:** CAT uses task-based SBA; Grade 12 commonly uses 25% SBA + 25% PAT + 50% exams, while Grades 10–11 follow the school POA with PAT-style practical work.

## Notes
Term 2 has a strong integration emphasis. Learners should move fluidly between theory topics and the applications that implement them.
