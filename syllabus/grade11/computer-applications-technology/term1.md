# Grade 11 — Computer Applications Technology: Term 1

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Systems technologies and accessibility
- **Key concepts:** information processing cycle, hardware, storage, accessibility options, hardware theft and protection, computer management
- **Skills / outcomes:** explain hardware choices, manage files and settings and evaluate hardware for different users and contexts
- **Assessment angles:** hardware comparison questions, accessibility scenarios, short theory items on storage and input/output

### Advanced application skills
- **Key concepts:** word processing, templates, forms, spreadsheets, absolute cell references, functions, database structure, tables, queries, reports
- **Skills / outcomes:** produce richer documents, use spreadsheet functions accurately and create basic database objects
- **Assessment angles:** practical application tasks, formatting corrections, formula design, database terminology and structure questions

## Assessment
- **Formal tasks this term:** Theory test and practical test by the end of the term.
- **SBA weighting:** CAT uses task-based SBA; Grade 12 commonly uses 25% SBA + 25% PAT + 50% exams, while Grades 10–11 follow the school POA with PAT-style practical work.

## Notes
Grade 11 assumes Grade 10 practical fluency. Spreadsheet referencing and database structure become noticeably more important.
