# Grade 12 — Information Technology: Term 1

Source: CAPS Information Technology Grades 10-12 (original CAPS; the 2024 Section 3 amendment was not checked), Section 3 Grade 12 Terms 1-4 (pp. 40-47) and Section 4 (programme of assessment).

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Database design and management
- **Key concepts:** database design and concepts (normalisation, entities and keys, transaction processing, characteristics of a good database); database management (protecting data, audit trail, SQL injection, DBA and programmer roles)
- **Skills / outcomes:** as set out in the CAPS Grade 12 plan for this term
- **Assessment angles:** theory and practical tasks on the CAPS content listed

### Hardware, networks and e-communications
- **Key concepts:** hardware: mobile technologies, performance factors, motivate a system for a purpose; networks: setting up, sharing concepts, remote access; e-communications: encryption, SSL, certificates
- **Skills / outcomes:** as set out in the CAPS Grade 12 plan for this term
- **Assessment angles:** theory and practical tasks on the CAPS content listed

### Social implications
- **Key concepts:** environmental impact, staying informed, upgrades
- **Skills / outcomes:** as set out in the CAPS Grade 12 plan for this term
- **Assessment angles:** theory and practical tasks on the CAPS content listed

### Application development
- **Key concepts:** simple user-defined class, instantiate, method types (constructor, accessor, mutator, auxiliary); accessing a relational database from code, single join with WHERE (maximum 2 tables), dataset navigation and modification, dataset event handlers; multi-form GUI and sharing data among forms; sorting, string and date/time routines; defensive programming and validation; text-based report; remove duplicates
- **Skills / outcomes:** as set out in the CAPS Grade 12 plan for this term
- **Assessment angles:** theory and practical tasks on the CAPS content listed

### Software engineering
- **Key concepts:** test and validate, document, motivate and evaluate solutions; methodologies (waterfall, RAD, incremental, agile); start the PAT; design tools (TOE, IPO, CRC, UML)
- **Skills / outcomes:** as set out in the CAPS Grade 12 plan for this term
- **Assessment angles:** theory and practical tasks on the CAPS content listed

## Assessment
- **Formal tasks this term:** Theory test and practical/programming test.
- **SBA weighting:** Grade 12 IT commonly uses 25% SBA + 25% PAT + 50% NSC examinations.
