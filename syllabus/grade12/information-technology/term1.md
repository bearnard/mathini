# Grade 12 — Information Technology: Term 1

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Advanced OOP and program design
- **Key concepts:** inheritance, polymorphism, encapsulation, abstract thinking, GUI design, exception handling, advanced debugging
- **Skills / outcomes:** design and extend class hierarchies, handle errors cleanly and justify OOP design choices
- **Assessment angles:** class-diagram questions, code-completion items, output tracing and bug-fixing

### Algorithmic refinement
- **Key concepts:** modular problem solving, recursion or advanced logic patterns, robust validation, testing strategies
- **Skills / outcomes:** write more elegant and reusable code and test solutions systematically
- **Assessment angles:** algorithm design, test-data selection, efficiency and correctness prompts

## Assessment
- **Formal tasks this term:** Theory test and practical/programming test.
- **SBA weighting:** Grade 12 IT commonly uses 25% SBA + 25% PAT + 50% NSC examinations.

## Notes
Programming may still be taught in Delphi or Python, but the Grade 12 demand is language-independent: learners must reason about robust OOP design and high-level problem solving.
