# Grade 12 — Mathematics: Term 3

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–10

## Topics

### Euclidean Geometry
- **Key concepts:** similarity, proportional reasoning, parallel-line theorems and formal riders
- **Skills / outcomes:** apply theorems rigorously and communicate reasons in a proof sequence
- **Assessment angles:** midpoint theorem, similarity proof steps, rider structure and theorem selection
- **Approximate time:** About 2 weeks

### Statistics: Regression and Correlation
- **Key concepts:** scatter plots, least-squares regression line, interpolation, extrapolation and correlation
- **Skills / outcomes:** interpret bivariate data, estimate values and judge whether predictions are sensible
- **Assessment angles:** correlation direction, interpolation vs extrapolation, regression-line use
- **Approximate time:** About 2 weeks

### Counting and Probability
- **Key concepts:** fundamental counting principle, Venn diagrams, trees, contingency tables and compound events
- **Skills / outcomes:** count systematically and calculate probabilities for dependent or independent events
- **Assessment angles:** counting-principle setup, event overlap, tree and table interpretation
- **Approximate time:** About 2 weeks

### Preliminary Examination Preparation
- **Key concepts:** integration of the full curriculum with emphasis on exam style and error analysis
- **Skills / outcomes:** consolidate full-year content and use feedback from timed practice to target weaknesses
- **Assessment angles:** full-paper integration, exam technique, error correction from prelim practice
- **Approximate time:** About 4 weeks including prelims

## Assessment
- **Formal tasks this term:** Formal test and the preliminary examinations.
- **SBA weighting:** FET CAPS: school-based assessment 25% of the promotion mark and examinations 75%.
