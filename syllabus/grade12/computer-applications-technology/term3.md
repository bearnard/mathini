# Grade 12 — Computer Applications Technology: Term 3

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### PAT completion and system management
- **Key concepts:** processing and analysing information, operating-system utilities, backup, antivirus, performance, file management, PAT phase 3
- **Skills / outcomes:** complete the PAT to standard and manage files and system tools confidently during practical work
- **Assessment angles:** information-management decisions, utility-tool questions, PAT moderation evidence

### Communications, social implications and advanced applications
- **Key concepts:** digital communications, browsers, AI, VR and AR, social networking, advanced spreadsheets, databases, HTML and linked documents
- **Skills / outcomes:** evaluate current digital technologies and solve practical application tasks that integrate data, documents and design
- **Assessment angles:** emerging-tech theory, advanced practical corrections, prelim-style mixed questions

## Assessment
- **Formal tasks this term:** PAT phase 3 and trial examination.
- **SBA weighting:** Grade 12 CAT commonly uses 25% SBA + 25% PAT + 50% examinations.

## Notes
Term 3 is the last major practical consolidation phase before prelims. Strong transfer of skills between applications is essential.
