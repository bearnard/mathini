# Grade 12 — Computer Applications Technology: Term 2

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Networks and web design
- **Key concepts:** wide area networks, network completion, social implications, HTML, web design, usability and communication tools
- **Skills / outcomes:** explain communication infrastructure and produce structured, usable web pages for set scenarios
- **Assessment angles:** network terminology, HTML and layout fixes, web-usability questions

### Solution development and PAT
- **Key concepts:** spreadsheets, word processing, databases, information management, PAT phase 2, June exam preparation
- **Skills / outcomes:** complete cross-application tasks, refine PAT evidence and prepare for the mid-year practical and theory papers
- **Assessment angles:** integrated practical tasks, advanced spreadsheet formulas, report and database design questions

## Assessment
- **Formal tasks this term:** Alternative task, PAT phase 2 and the mid-year practical and theory examinations.
- **SBA weighting:** Grade 12 CAT commonly uses 25% SBA + 25% PAT + 50% examinations.

## Notes
Term 2 is intensely practical. Learners should balance PAT progress with formal June-exam preparation.
