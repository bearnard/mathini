# Grade 7 — Afrikaans First Additional Language: Term 2

**CAPS phase:** Intermediate Phase (Gr 6–7)
**ATP weeks:** Weeks 1–10

## Topics

### Poetry and continued text study
- **Key concepts:** poësie, stanza, rhyme, imagery, prescribed reading
- **Skills / outcomes:** respond to poems and connect poetry language to meaning
- **Assessment angles:** imagery and mood questions, line-reference items

### Formal correspondence and essays
- **Key concepts:** formele brief, descriptive essay, narrative essay, register, format
- **Skills / outcomes:** write a formal letter and a longer essay with suitable tone and structure
- **Assessment angles:** layout conventions, register choices, essay planning

### Assessment-focused language practice
- **Key concepts:** comprehension, visual text, language structures, oral preparation
- **Skills / outcomes:** prepare for a controlled test using reading and grammar strategies
- **Assessment angles:** visual-literacy hooks, language correction, comprehension recall

## Assessment
- **Formal tasks this term:** Formal oral work and a controlled test that usually combines comprehension, visual text and language use.
- **SBA weighting:** Not stated as a fixed term percentage in the ATP; tasks feed the annual SBA programme.

## Notes
Term 2 usually increases formality in writing and introduces more explicit poetry analysis.
