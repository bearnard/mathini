# Grade 10 — Computer Applications Technology: Term 1

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Computer systems and file management
- **Key concepts:** types of computers, data and information, desktop GUI, access control, keyboarding, drives, folders, files, naming conventions, basic hardware and software
- **Skills / outcomes:** log on, organise files, navigate the interface, explain hardware/software basics and apply safe computer-management routines
- **Assessment angles:** theory MCQs on hardware/software, practical file-organisation tasks, shortcut and desktop questions

### Word processing fundamentals
- **Key concepts:** workspace, document structure, text entry, editing, formatting, paragraph layout, page layout, proofing, illustrations
- **Skills / outcomes:** create and edit documents, use formatting tools, insert objects and apply basic layout conventions
- **Assessment angles:** screen-based practical tasks, formatting fixes, short theory questions on word-processing concepts

## Assessment
- **Formal tasks this term:** Theory or combination test by the end of the term.
- **SBA weighting:** CAT uses task-based SBA; Grade 12 commonly uses 25% SBA + 25% PAT + 50% exams, while Grades 10–11 follow the school POA with PAT-style practical work.

## Notes
Based on CAPS and the 2023/24 DBE ATP. CAT Grade 10 starts with systems technologies and quickly moves into practical word processing, with ergonomics and digital citizenship threaded through the term.
