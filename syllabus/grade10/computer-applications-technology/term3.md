# Grade 10 — Computer Applications Technology: Term 3

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Internet, communication and networks
- **Key concepts:** internet and WWW, browsers, search engines, e-mail, attachments, netiquette, POPI awareness, communication devices, digital citizenship
- **Skills / outcomes:** use internet tools appropriately, communicate safely online and explain basic networking and communication concepts
- **Assessment angles:** internet-technology definitions, online-safety scenarios, communication-method questions

### Application development and web basics
- **Key concepts:** spreadsheets, word processing, presentations, HTML syntax, basic tags, web design, PAT phase 1 information management
- **Skills / outcomes:** solve spreadsheet problems, produce presentations, create simple web pages and begin PAT-style information handling
- **Assessment angles:** practical software tasks, HTML tag correction, PAT evidence prompts, theory/practical integrated questions

## Assessment
- **Formal tasks this term:** Practical test, alternative/theory test and PAT phase 1 work.
- **SBA weighting:** CAT uses task-based SBA; Grade 12 commonly uses 25% SBA + 25% PAT + 50% exams, while Grades 10–11 follow the school POA with PAT-style practical work.

## Notes
Term 3 is application-heavy. Learners should start showing integration across spreadsheets, documents, presentations and basic HTML while working through PAT phases.
