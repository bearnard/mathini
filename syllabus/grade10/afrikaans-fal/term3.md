# Grade 10 — Afrikaans First Additional Language: Term 3

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–10

## Topics

### Literature analysis and response
- **Key concepts:** drama, prose, poetry, literary features, oral response
- **Skills / outcomes:** answer literature questions with clearer evidence and terminology
- **Assessment angles:** theme support, poetry device hooks, contextual response

### Transactional writing set
- **Key concepts:** formal letters, reports, interviews, statements, speeches
- **Skills / outcomes:** write practical texts with appropriate format and register
- **Assessment angles:** format recall, register, audience-purpose questions

### Language reinforcement
- **Key concepts:** editing, sentence structure, listening tasks, exam practice
- **Skills / outcomes:** maintain language accuracy while preparing for end-of-year assessment
- **Assessment angles:** editing items, sentence correction, listening recall

## Assessment
- **Formal tasks this term:** Oral task, formal writing task and a controlled test.
- **SBA weighting:** Not usually expressed as a per-term percentage in the ATP; tasks contribute to the annual SBA programme.

## Notes
Term 3 often increases the demand for independent literature response and more formal writing.
