# Grade 10 — Information Technology: Term 2

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Control structures and modular programming
- **Key concepts:** selection, repetition, functions, procedures, string handling, validation, simple debugging
- **Skills / outcomes:** write modular code, test logic and improve readability with clear decomposition
- **Assessment angles:** find-the-bug questions, function/procedure design, trace-table questions

### Database and introductory object concepts
- **Key concepts:** basic SQL, tables, fields, records, simple queries, introductory classes and objects, data files
- **Skills / outcomes:** design simple tables, query data and connect problem statements to suitable data structures
- **Assessment angles:** SQL basics, class-vs-object explanations, simple schema and query items

## Assessment
- **Formal tasks this term:** Mid-year practical examination and mid-year theory examination.
- **SBA weighting:** For Grades 10–11, 2023 ATP mediation indicates SBA converts to 40% and examinations to 60%; PAT work is built into the year programme.

## Notes
Term 2 deepens programming and introduces formal database thinking. Teachers usually expect stronger code tracing and more careful validation by this stage.
