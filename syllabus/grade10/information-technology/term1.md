# Grade 10 — Information Technology: Term 1

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Computer systems, data representation and algorithm design
- **Key concepts:** hardware and software basics, data and information, number systems, binary and hexadecimal, flowcharts, pseudocode, problem decomposition
- **Skills / outcomes:** represent simple logic visually, convert basic number systems and explain core IT system concepts
- **Assessment angles:** trace algorithms, number-system conversion items, hardware/software terminology questions

### Programming foundations
- **Key concepts:** Delphi or Python basics, variables, input/output, selection, iteration, basic OOP ideas, simple testing
- **Skills / outcomes:** write simple console programs, trace code and build algorithms that use decisions and loops
- **Assessment angles:** dry-run tables, output prediction, simple coding snippets and debugging hooks

## Assessment
- **Formal tasks this term:** Theory test and practical/programming test.
- **SBA weighting:** For Grades 10–11, 2023 ATP mediation indicates SBA converts to 40% and examinations to 60%; PAT work is built into the year programme.

## Notes
Programming may be taught in Delphi or Python depending on the school. Grade 10 emphasises algorithmic thinking before learners tackle larger solution-development tasks.
