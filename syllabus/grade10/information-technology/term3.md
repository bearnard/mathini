# Grade 10 — Information Technology: Term 3

**CAPS phase:** FET Phase (Gr 10–12)
**ATP weeks:** Weeks 1–11

## Topics

### Networks and data handling
- **Key concepts:** networks, internet basics, topologies, communication media, lists or arrays, simple files, data processing
- **Skills / outcomes:** explain network components, store and process collections of data and choose appropriate structures for a problem
- **Assessment angles:** network diagrams, list-processing code, file-handling prompts, basic query questions

### Integrated solution development
- **Key concepts:** problem-solving strategies, practical programming tasks, validation, debugging, PAT-style integration
- **Skills / outcomes:** combine programming, data and interface ideas into longer tasks and improve programs iteratively
- **Assessment angles:** integrated coding scenarios, error fixing, reasoning about efficiency and correctness

## Assessment
- **Formal tasks this term:** Alternative/integrated task, practical test and PAT-style development work.
- **SBA weighting:** For Grades 10–11, 2023 ATP mediation indicates SBA converts to 40% and examinations to 60%; PAT work is built into the year programme.

## Notes
By term 3, Grade 10 IT should look more integrated: learners must move between algorithm design, coding, files and networks without treating them as isolated topics.
