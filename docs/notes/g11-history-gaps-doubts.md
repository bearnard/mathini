# Grade 11 History gaps: points for a teacher to confirm

Source: DBE CAPS FET History Grades 10-12, Afrikaans edition (Geskiedenis/KABV), Grade 11 Topic 3 (Australia case study) and Topic 4 (Afrikaner nationalism). Every source box is an original or paraphrased description written for the lesson and labelled as such; no real speech, photograph or testimony is quoted. Dates live in `_shared/gaps11Facts.ts` and are asserted in `src/g11HisGaps.test.ts`.
