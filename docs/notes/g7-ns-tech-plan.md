## Drawing techniques by grade (CAPS Technology Gr 7-9)

Checked against the CAPS text so each lesson teaches only its own grade's list.

- Grade 7, Term 1, Communication skills: "Conventions: outlines (thin/dark); construction lines (thin/feint); hidden detail (dashed) scale; dimensioning." / "Working Drawings: two-dimensional drawing of ONE face of an object using conventions" / "3D oblique - front view with depth at 45o (use squared 'quadrant' paper); oblique projection used to assist with interpretation, and with drawing single VP perspective." / "3D artistic - single vanishing point perspective with colour, texture and shading."

- Grade 9, Term 1: first angle orthographic projection and isometric (plan of stair and ramp). Already in the existing G9 T1 lessons.

This is the Grade 9 perspective lesson (branch 5).
