# Grade 11 Information Technology, 2024 amendment, branch A: points for a teacher to confirm

Source: the 2024 CAPS amendment, Grade 11 teaching plan (DBE Circular S9 of 2025: it applies to Grades 10 to 12 from January 2026). Comparison: `audit/it-2024-amendment-check.md`.

| # | Lesson | What | Why it is uncertain |
|---|---|---|---|
| 1 | Motherboard, memory and caching | Data paths: storage, RAM, CPU and RAM, VRAM, GPU. | Simplified; the amendment lists the paths without detail. |
| 2 | System software | Compiler (whole program first) versus interpreter (line by line). | Delphi compiles; the lesson describes the general idea. |
| 3 | Network innovation | Extranet is "part of an intranet shared with chosen outsiders". | Textbook definitions vary slightly. |
| 4 | Computer management threats | Everything is described, nothing is instructed. Malware types follow the amendment's list. | None. |
| 5 | Sorting | Selection and bubble sort shown on 5, 3, 8, 1 and recomputed in `g11ItAmendmentA.test.ts`. | The amendment says learners need only apply ONE sort for the PAT. |
| 6 | Parallel arrays | Sorting one array means swapping in the others. | None. |
| 7 | Mobile and wireless | Shaping is "giving some traffic priority", throttling is "slowing a connection". | Providers use the words loosely. |
| 8 | Digitalisation | The careers are the amendment's examples. The gig economy is described neutrally with its trade-offs. | None. |
| 9 | DBMS | Product names are the amendment's examples; no product is recommended. | None. |
| 10 | User-defined methods | Delphi examples use `CalcVAT`; value parameters only (the amendment says "Value parameters only"). | `var` parameters are not taught. |

Term moves in branch A (no content change): Computer Architecture to Term 1, File Handling to Term 2, Network Topologies to Term 1, Protocols and Transmission Media to Term 2.
